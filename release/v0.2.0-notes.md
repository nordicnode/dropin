# dropin v0.2.0

The universal Linux installer — now truly all-in-one for archives, with a polished new look.

## Highlights

**Pure-Rust archive handling.** No more shelling out to `unzip`, `tar`, `7z`, or `ar`. Dropin now extracts zip (including zstd-compressed), tar.gz, tar.bz2, tar.xz, tar.zst, and .deb files natively. Your VHOLUME-style game archives with zstd compression just work.

**Faster installs.** Archives are extracted once, not three times. The preview dialog caches its extraction; the real install reuses it with a fast rename.

**New look.** Sophisticated dark theme with emerald accent, polished buttons and cards, better badges, and a proper search field.

**Better errors.** Zip failures now explain what went wrong (corrupted? zstd? disk full?) instead of dumping a raw command. Error dialogs have a Copy button and scroll.

## All changes since v0.1.0

- Pure-Rust zip/tar/ar extraction (no external tools)
- Extraction cache: plan once, install reuses
- Unique temp dirs (no collisions between parallel installs)
- Temp cleanup on all error paths
- UI redesign: dark theme, emerald accent, polished components
- Dialog cutoffs fixed (scrollable content, fixed buttons)
- Copy error button on failure dialogs
- Windows .exe icon extraction
- Proton/GE-Proton support with automatic per-game fixes
- Zero-friction Wine setup with DXVK
- Panic fixes, traversal protection tests
- 89 tests passing, zero warnings

## Install

```bash
tar -xzf dropin-v0.2.0-x86_64-linux.tar.gz
cd dropin-v0.2.0
./install.sh
```

## Requirements

Linux x86_64. Fully offline — no accounts, no telemetry, no network calls except the ones you ask for (update checks, GitHub release tracking).
