# dropin v0.2.1

The universal Linux installer — CLI-only from here on, with Lutris-style game adoption.

## Highlights

**CLI-only.** The GUI is gone. One tool, one interface: `dropin` subcommands. Everything the manager did — install, list, update, rollback, remove, doctor — was already in the CLI.

**`dropin adopt <dir>`** — add an already-installed game, Lutris-style. Point it at a game folder and dropin scans for executables, registers it with a `.desktop` entry and uninstall tracking, without moving anything. Runs in the background with a progress spinner.

**Proton launch diagnostics.** Failed game launches capture their output and tell you what's actually wrong (driver issues, Vulkan failures, missing setup) instead of dying with a bare exit code.

**E2E-hardened.** A full pass installing real games found and fixed real problems: Windows zip extraction bugs, adopt cleanup bugs, and 7 UX issues.

## All changes since v0.2.0

- Remove GUI (CLI-only going forward)
- `dropin adopt`: Lutris-style adoption of pre-installed game folders
- Adopt runs in the background with a progress spinner
- Proton launch-failure diagnostics with actionable advice
- Windows zip extraction fixes
- Adopt cleanup fixes
- Automatic Wine/Proton setup: `dropin setup-wine` / `dropin setup-proton`
- README rewritten CLI-first

## Install

```bash
tar -xzf dropin-v0.2.1-x86_64-linux.tar.gz
cd dropin-v0.2.1
./install.sh
```

## Requirements

Linux x86_64. Fully offline — no accounts, no telemetry, no network calls except the ones you ask for (update checks, GitHub release tracking).
