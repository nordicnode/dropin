# dropin v0.1.0

The universal Linux installer for all the weird files the internet hands you. Download it, double-click it, done — no terminal, no root, and everything tracked so uninstalls are actually clean.

## What it does

- **Installs anything**: AppImage, .deb, .rpm, .tar.gz/.zip, .flatpakref, installer scripts — magic-byte detection, rootless into `~/Applications` + `~/.local/opt`
- **GUI-first**: double-click any installer for the review dialog, or open **dropin** from your app menu for the full manager (updates, rollback, remove, GitHub tracking, doctor)
- **Real uninstall ledger**: every file tracked in SQLite; `remove` reverses it, `--purge` trashes leftovers
- **Trust**: offline checksum verification (✓ badge), safe AppImage metadata extraction without executing anything
- **Updates done right**: native zsync delta updates (only changed blocks), GitHub release tracking for AppImages without zsync, pre-update snapshots with one-click rollback
- **Doctor**: finds orphaned installs, duplicates, menu shadowing, cross-source installs, and broken menu entries

## Install

```bash
tar -xzf dropin-v0.1.0-x86_64-linux.tar.gz
cd dropin-v0.1.0
./install.sh
```

Or `cargo install --path crates/dropin-cli` if you prefer building from source.

## Requirements

Linux x86_64. Fully offline — no accounts, no telemetry, no network calls except the ones you ask for (update checks, GitHub release tracking).
